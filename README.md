Entry for [The Moon Finally Answers Back](https://make.fun/bounty/u-mang-the-moon-finally-answers-back-781a7ec1) on [make.fun](https://make.fun) — one line, in the voice of the Moon, finally replying to four billion years of wishes, howls and late-night promises.

## What it does

`main.py` writes the Moon's comeback — a single line of at most 239 characters — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), validates it is one non-empty line within the limit, then re-reads the file to verify it matches exactly.

## Run it

```sh
python3 main.py
```

## The line

> Look, I've heard every wish, howl, and 2 a.m. promise for four billion years — and not one of you has ever once wished ME a good night.
